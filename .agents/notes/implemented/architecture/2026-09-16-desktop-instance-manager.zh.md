# Agent Note: 独立于桌面标签页管理 Harness 进程

Status: implemented

[English](2026-09-16-desktop-instance-manager.md) | 中文

## 问题

桌面客户端需要在本地和远程 Agent 环境之间切换，同时避免混用凭据、会话或插件安装。远程任务必须能在桌面连接中断后继续，而退出应用不能遗留本地拥有的 Host 进程。

## 决策

管理器分开保存实例定义与打开的标签页，并区分进程状态和连接状态。每个本地实例拥有独立的 Harness home、Desktop profile、Host 控制器和持久浏览器分区，不可变的打包运行时资源仍共享。每个远程实例在预配置的 Linux SSH 主机上拥有专用 home 和 tmux 会话。

关闭标签页只释放视图，不停止 Agent。退出管理器会停止本地 Host 并断开远程传输。移除配置会保留数据。停止、重启、插件变更和 profile 重置都针对稳定的实例 ID。启动取消先于完整清理执行，关闭或停止后拒绝过期的视图创建。

实例显示名称的编辑保留实例 ID、打开的标签页、现有连接和浏览器视图。修改名称不得获取或释放运行时归属。软件偏好是统一来源，与实例定义分开持久化。已连接及后续连接的实例通过带修订号校验的 DSH 设置写入继承外观、语言和输入行为，实例值不会更新软件偏好。窗口快捷键归软件所有，在嵌入视图中同样可用。设置使用一个可关闭的外壳标签页，实例管理属于其全高侧栏中的分类；应用与外观偏好分别放在独立页面，内容独立滚动。切换或关闭设置只改变外壳视图，不释放实例连接。窗口使用无原生边框的标签栏，空白区域可拖动，交互控件不可拖动。受认证管理 IPC 保护的窗口按钮操作 Electron 窗口；最大化事件同步按钮状态，关闭按钮进入现有应用退出和 Host 清理流程。

软件模型 Key 在本地通过操作系统加密，随后下发到各已连接实例的现有凭据提供方，管理器渲染进程只接收元数据。移除标记持久保存，以便离线实例重新连接时清理已删除的软件 Key。DSH 设置表单拥有明确的非密钥配置，涵盖轮次显示、预设选择和 DeepSeek，在没有实例时也可编辑。固定字段允许列表阻止任意 RPC 和密钥配置，相关字段通过一次带修订号校验的命名空间写入更新。连接实例和修改软件设置时，软件值覆盖受管理的实例字段，保留其他字段。不支持的命名空间和被拒绝的写入会显示错误，同时保留连接和已保存的软件值；支持的命名空间继续同步。

模型来源使用软件分配的稳定归属 ID，与可编辑的名称、地址和协议无关。每个来源派生独立的提供方路由和加密凭据引用，因此使用同一协议的两个网关也相互独立。来源配置和替换密钥同时提交，替换值留空时保留密钥。同步仅修改 `llm-pi-ai` 中这些受管理路径，不替换整个提供方映射。删除标记为离线实例持续保留，防止后续连接恢复已删除的路由或凭据。明确的模型目录使自定义接口无需把实例模型目录导入软件偏好即可注册。

本地 Web UI 请求沿用现有分帧管道传输，并在实例浏览器分区上注册。远端 Web UI 流量经过认证的 SSH 隧道，使用远端自身的客户端资源。只有确切的管理器和插件窗口主框架能够调用管理 IPC。Agent 页面不会获得进程或 SSH 权限。

SSH 密码和私钥口令仅存于内存。首次确认后按端点固定主机密钥。远程生命周期命令引用路径参数，检查归属标记与 tmux 身份，不安装 DSH，也不接管无关数据目录。显式[插件注入](2026-10-23-shell-plugin-library-and-instance-injection.zh.md)在所属远端 profile 中准备选定插件。生命周期日志排除认证 URL 和本次会话密钥。

本决策部分替代[桌面打包决策](2026-08-25-electron-desktop-packaging-and-updates.zh.md)中的单 profile 与共享数据归属，原有运行时和版本约束仍适用。[内置运行时决策](2026-09-08-desktop-bundled-runtime-and-external-plugins.zh.md)与[原地 profile 变更决策](2026-09-09-desktop-in-place-profile.zh.md)在每个本地 home 内独立适用。这些记录仍保留独立的打包和事务依据，不进行归档。

## 考虑过的替代方案

**单后端的项目标签页。** 这种方式共享插件激活、凭据与运行时故障，无法提供独立 Agent 环境。

**关闭标签页时停止远程任务。** 这种方式把远端工作绑定到桌面连接的可用性，无法支持远程长任务。

**自动部署与常驻管理守护进程。** 第一版面向预装的 DSH 和 tmux，额外部署协议和服务生命周期会在连接管理建立之前扩大远端支持范围。

**所有远端版本共用一个客户端 bundle。** 使用远端自身 UI 可保留其功能展示。共享软件设置仅使用少量允许的现有 DSH API，专有配置仍归原生分区管理。

## 后果

多个本地 Host 比共享进程的项目标签页消耗更多内存。远程进程需要显式停止，不会在服务器重启后恢复。远端版本兼容性限于当前上游版本验证过的启动与 Web 流程。自定义管理器关闭官方自动更新。

注册表、生命周期、IPC 和真实 SSH 协议测试覆盖隔离、取消、认证失败、主机信任、隧道及连接中断。Electron 冒烟测试使用两个真实本地 Host 和 UI 视图。协议测试服务不能确立真实模型的远程验收结果，后者需要配置好的 Linux DSH 部署与模型凭据。

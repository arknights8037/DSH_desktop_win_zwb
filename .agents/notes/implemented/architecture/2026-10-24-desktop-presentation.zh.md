# Agent Note: 桌面外壳拥有实例展示

Status: implemented

[English](2026-10-24-desktop-presentation.md) | 中文

## 问题

嵌入客户端绘制不透明应用背景时，软件壁纸设置无法形成连续的桌面画布。仅同步命名空间还会让视觉定制依赖远端服务器的设置 schema。独立的设置外壳为软件偏好提供了相互竞争的入口。

## 决策

桌面管理器只绘制一次壁纸及其可选蒙版。实例 WebContentsView 使用透明背景。主进程拥有的作者来源样式表清除嵌入文档画布，并通过带 important 优先级的 DSH 语义 token 提供经过验证的分区和前景颜色。实例重载会重新安装样式表，软件编辑会替换它，视图销毁会丢弃其键。作者来源允许在 Electron 44 中撤回样式；桌面探测中，用户来源样式在移除后仍然残留。展示先于设置 RPC 应用，即使该 RPC 失败仍可生效。侧栏列只绘制一次底色；输入区渐变接受桌面提供的透明填充。DSH 保留工作区、会话、输入、首次使用引导及插件行为。

实例 preload 只暴露载体标记和打开软件设置的请求。主进程认证所属实例的主框架，将该请求转发到现有外壳设置标签页。浏览器客户端保留自身设置面板。自动引导和功能定向的设置分区仍归实例所有。远端实例保留自身客户端资源；匹配的语义 token 和设置导航集成决定其支持的展示范围。

此决策部分替代[实例管理决策](2026-09-16-desktop-instance-manager.zh.md)中仅通过主题设置控制展示的选择。原记录仍拥有独立的进程、隔离、凭据和软件设置决策，因此保持活跃。经过验证的可携带图片存储及带修订号校验的设置同步仍然适用；桌面样式表是应用内的视觉权威来源。

壁纸模式下，每个外壳区域只绘制一次底色。嵌套的设置卡片和实例行保持透明，因为重复绘制 80% 底色会让实际不透明度升至 96%。当前标签也共用父级顶部栏底色，通过强调色下划线标识选中状态。欢迎卡片没有带底色的父区域，因此自行绘制内容区底色。悬停底色保持半透明，菜单和弹窗则保留实色填充，确保重叠内容可读。

未保存的外观草稿由桌面主进程持有，直到保存或取消。外壳通过仅供管理器使用的 IPC 转发经过验证的预览，各实例已有的同步队列串行替换样式表。预览请求不写入软件设置，也不调用后端设置 API。新建及重载的实例视图使用当前草稿；取消和管理器重载会恢复已保存的展示。这样可以在预览时让壁纸透过会话显示，同时避免持久保存尚未确定的选择。

内置外观适配层属于外壳发行内容，独立于内核发行文件和实例插件依赖图。壁纸模式会清除旧版基础背景 token 和嵌套页面填充，并通过具名的 `root`、`main` 和 `sidebar` 槽位定位各区域只绘制一次底色的列。支持桌面填充 token 的会话根容器也在所属列之上保持透明。浮动菜单和弹窗在本地获得实色填充 token。槽位选择器适用于延后挂载的页面和 CSS Module 重新构建，无需生成的类名或 mutation observer。

外壳将动效插件作为一份样式表分发，供管理器和注入的实例视图共用。`appearance.motionEnabled` 默认值为 true，旧版软件设置缺少该字段时也使用此值，非布尔值会被拒绝。外观开关即时保存；已有视图通过队列在设置 RPC 前替换样式，后续加载则使用保存的选择。仅当实例公布原生动效字段时才会向其同步选择。CSS 媒体查询只在系统允许时启用附加动效。选择器面向语义控件和浮动表面，保持对话文本及滚动行为不变。进入动画完成后释放位移，避免持续为定位后代建立包含块。插件关闭时，客户端原生动画仍归客户端拥有。

共享设置按命名空间及字段独立匹配各实例序列化后的 schema。同一映射也提供管理器的修改白名单。提供方与模型组成可选字段对，同时留空时保留实例选择。推理强度在实例公布默认模型设置时写入该处，否则使用 DeepSeek 提供方字段。枚举选项和数值范围用于控件及下发前校验；缺失字段明确标为不支持。软件选择在本地及 SSH 实例间保持统一来源，不导入实例值。内核版本推断无法描述独立组合的插件，因此一个命名空间的存在不会移除另一命名空间支持的控件。

## 考虑过的替代方案

**只同步主题设置。** 这会保留客户端的不透明层，并让桌面外观依赖后端 schema 接受个人定制。

**在 Electron 中重建所有客户端视图。** 这会重复工作区和会话行为，且无法保留远端服务器自身的功能 UI。

**向嵌入页面提供管理器桥接。** 设置导航不需要进程、凭据或实例修改能力。独立的认证请求让这些权限保留在外壳中。

**向每个内核 profile 安装外观插件。** 特定内核的客户端加载方式和包兼容性会成为外壳壁纸的前置要求。外壳拥有的 CSS 注入让本地及 SSH 展示独立于后端插件安装和内核替换。

**观察每次 DOM 变更并为新内容添加动画。** 流式回复和频繁重建的控件会反复播放动画。语义 CSS 选择器无需观察器、对话订阅或会话事件，即可覆盖延后挂载的内容。

## 影响

语义 token 名称和具名槽位的祖先结构构成对嵌入客户端的展示依赖。未知远端组件可能保留不透明表面，缺少导航集成的旧客户端会保留自身设置入口。设置 RPC 失败独立于展示继续可见。栅格图片由外壳绘制，因此蒙版和裁剪在标题栏与实例视口之间连续。

专项测试覆盖导航认证、重载安装和设置 RPC 被拒。Electron 冒烟显示实际会话，检查合成后的壁纸像素，截取可见窗口，并沿实例设置入口打开外壳标签页。这些检查无需模型凭据。

无界面 Chromium 回归覆盖已发行和支持桌面填充 token 的布局夹具、延后挂载的内部页面、每列单次填充、实色浮动表面、浅深配色、零与全不透明度，以及样式表撤回。这些夹具验证 CSS 合成，不能替代针对新发行内核实际槽位祖先结构的验收检查。

动效回归覆盖旧版偏好文件、重启后持久保存、无效 IPC 及磁盘值、本地化设置快照、已有视图替换、重载、减少动态效果、样式表移除、不添加动画的对话文本，以及位移清理。管理器和实例使用同一份样式表，因此远端客户端需要兼容的 HTML 语义，无需新增内核插件。

设置回归覆盖两代命名空间共存、带修订号校验的下发、schema 范围、可选模型选择、只读提供方、缺失字段、值未变化及已公布的原生动效。本地化控件快照记录共享设置入口。这些检查使用所属设置 schema 和夹具传输；真实内核验收仍需单独执行。

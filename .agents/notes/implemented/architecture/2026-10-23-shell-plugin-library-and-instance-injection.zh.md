# Agent Note: 外壳拥有插件安装并向实例部署独立副本

Status: implemented

[English](2026-10-23-shell-plugin-library-and-instance-injection.md) | 中文

## 问题

通过各实例分别安装插件会将发现和版本管理绑定到实例可用性。共享可变插件目录又会让库更新改变运行中的实例，阻碍独立的依赖版本。Windows 原生依赖不能供 Linux SSH Host 使用。

## 决策

桌面外壳的全局软件设置拥有插件库、社区市场、版本审阅和实例注入，这些操作不会移入 DSH Web 设置页。插件库独立保留精确版本选择，不依赖平台安装。本地依赖缓存按需准备，以应用运行时身份区分。主进程只接受所属窗口的插件库变更。添加或移除库中版本不会修改已有实例部署。

本地注入将选定依赖图及其锁文件复制到目标 Profile，排除应用拥有的 Host 包。受管理的顶层链接只指向该 Profile 内的独立副本。Host peer 保持应用的模块身份，私有依赖从复制的依赖图解析。旧式 pnpm 操作排除注入依赖，随后恢复它们的链接。配置归实例所有，替换时保留本地启用状态。插件库保留源直到部署完成，退出应用会等待该操作。

远端注入通过实例的认证 Web Connection 发送 prepare 和 apply 请求。远端启动器使用该主机的 pnpm 和安装拥有的 Host 包，在当前 profile 下准备独立依赖图，禁用生命周期脚本。Apply 持久化重启请求，不改变运行中的模块。下次启动时，启动器替换选定包的链接和清单，仅在就绪后确认日志。若 applying 日志未完成，随后一次启动恢复原链接和清单。配置和禁用状态在替换后保留。SSH 仅负责隧道和进程启停，不接收插件安装或恢复脚本。缺少该 API 的服务端需要更新，不提供 SSH 安装回退。

本决策部分取代[内置运行时决策](2026-09-08-desktop-bundled-runtime-and-external-plugins.zh.md)的安装位置、[原地 Profile 决策](2026-09-09-desktop-in-place-profile.zh.md)的变更处理、[市场决策](2026-10-17-desktop-plugin-market-and-profile-recovery.zh.md)的计划归属，以及[实例管理器决策](2026-09-16-desktop-instance-manager.zh.md)的远端包操作范围。它们关于运行时身份、锁定、目录校验、恢复和生命周期的依据仍适用，没有记录被完全取代。

## 考虑过的替代方案

**让实例共享可变插件库目录。** 这可避免复制，但更新会隐式生效，运行中的实例也受库移除和文件写入影响。

**在各实例窗口保留 npm 安装。** 这可保留现有安装器，但安装归属仍分散在实例中，更新时会混合依赖图。

**将 Windows 依赖图复制到 SSH 实例。** 原生二进制和按平台选择的依赖无法在 Linux 运行。目标端准备以依赖字节不完全相同为代价，换取平台兼容性。

## 后果

独立副本和本地快照会占用磁盘空间，不自动回收。平台无关的版本选择让 Linux 专用插件无需 Windows 安装即可进入远端准备。本地运行时变化只使本地缓存失效，实例副本仍需显式重新注入。远端准备需要预装 DSH、tmux 和 pnpm，依赖生命周期构建的包需在实例端另行准备。部署待生效期间的 profile 编辑会被拒绝，不会被覆盖。激活日志只记录链接和清单变更，不包含插件外部副作用或会话数据。

所属测试目录中的双语界面预期覆盖全局插件库和实例选择。文件系统测试覆盖独立副本、冲突私有依赖版本、保留禁用状态和启动回滚。认证 HTTP 测试通过真实 Loader 树启动 API，验证授权、无效输入拒绝和路由释放。SSH 协议测试验证隧道中的 Web RPC，并拒绝安装 shell 命令。真实 pnpm 仓库测试验证私有依赖准备、禁用生命周期脚本和共享 Host 模块身份。Linux 原生包和任意第三方行为仍需部署验收。

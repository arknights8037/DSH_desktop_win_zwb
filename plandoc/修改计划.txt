DeepSeek Harness Desktop 执行计划

已完成

- Electron 桌面壳、窗口生命周期、后台崩溃重启和 NSIS Windows x64 打包。
- 内置官方 Harness Web UI 和生产依赖，服务固定监听 127.0.0.1。
- 后台改为使用安装包内独立 Node.js runtime，避免 Electron 内置 Node 启动 Win32 native picker 时触发 koffi/N-API 崩溃。
- 恢复官方 directory-picker-auto/native 组合，并由安装包内独立 Node runtime 启动 native picker；已实机触发 worker 验证通过。
- 代理仅通过当前构建环境注入，不写入源码和安装包配置。

当前执行顺序

1、workspace 权限和路径修复（已完成）
   - 已修复：后端启动 cwd 从持久化 workspace.json 解析，不再固定为 DSH_HOME；官方 sandbox-policy 的 process.cwd() fallback 与首个可用工作区一致。
   - 已修复：首选目录不存在或无权限时跳过，回退到下一个可用目录；无可用目录才回退到应用 home。
   - 已验证：当前绝对路径 F:\DSH_desktop_win_zwb、中文目录、UNC 路径 `\\localhost\F$\DSH_desktop_win_zwb`、无效目录跳过、受保护路径返回 EPERM、重启后 workspace.json 持久化；后端仍使用 workspace session cwd 优先级。
   - 已修复上游 Windows native picker 的两个缺陷：worker 使用 `close` 等待最终 IPC，UTF-16 路径按完整 code unit 识别 NUL；构建阶段自动应用补丁。
   - 已验证：独立 Node runtime 真实启动 native picker，触发取消后返回 `native directory picker aborted`，不再出现 worker 提前退出错误；通过 Windows UI Automation 导航到 `G:\NODEjs` 并返回准确路径，确认可跨盘符选择。
   - 验收标准：选择目录后能得到准确工作区路径；工具请求无 session cwd 时使用已保存 workspace，带 session cwd 时只使用该 session 的 canonical path。

2、移除 Electron 原生边框和默认按钮（已完成）
   - 已启用无边框窗口和隐藏默认菜单。
   - 已加入最小化、最大化/还原、关闭、双击标题栏切换和拖拽区域。
   - 已验证：真实 Electron renderer 加载 preload，标题栏高度 38px，三个按钮带 aria-label/tooltip，页面内容不被遮挡。

3、添加会话和项目置顶功能（已完成）
   - 已在官方 workspace/session 行注入可见星标按钮，支持 Pin/Unpin 和键盘焦点。
   - 已实现项目、会话独立置顶列表；置顶项优先排序，取消置顶恢复普通排序。
   - 已持久化到应用数据目录 `desktop-pins.json`，重启后恢复；空状态使用空数组，不影响官方 UI。
   - 已验证：真实 Electron renderer 中项目和两个会话均出现按钮，会话置顶后移动到列表顶部并在重启后保持。

4、重写插件管理器（已完成）
   - 已增加桌面插件管理入口，枚举官方内置插件及版本状态。
   - 已支持原生目录选择器安装本地插件，复制到应用 home/node_modules，不依赖用户安装 Node.js。
   - 已支持插件启用/关闭、移除、重启提示；通过 desktop patch 覆盖 Loader 状态。
   - 已保存安装版本和备份路径；后台启动失败时自动回滚最近一次插件变更并提示用户。
   - 已验证：真实 Electron renderer 显示 57 个插件卡片、版本号和安装按钮，后台 patch 生成测试通过。

5、记忆系统（已完成）
   - 已增加系统级、项目级、会话级独立记忆存储 `desktop-memory.json`。
   - 已按系统 > 项目 > 会话优先级合并，按文本去重解决重复冲突。
   - 已接入官方 `dsh-system-prompt` 动态 context；每轮模型请求会读取当前 DSH_HOME 下的合并记忆。
   - 已支持当前层添加、删除、清空，以及 JSON 导出。
   - 已验证：真实 Electron renderer 三层入口可见，添加后可见并删除后消失。

发布前验收

- 原生 Windows 目录选择器由独立 Node worker 启动；已修复 IPC race/UTF-16 路径问题，并通过真实打开/取消及跨盘符选择回归。PowerShell/bash/file 工具读写边界仍建议在目标用户环境做一次人工验收。
- API Key、模型请求、workspace 操作、会话持久化和应用退出清理通过。
- 无 Node.js 的 Windows x64 环境可安装并启动；输出 NSIS 安装包和 SHA-256。
